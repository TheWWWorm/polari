# Полари Вики

Энциклопедия цикла Романа Суржикова «Полари» на русском языке: https://polari.wwworm.com

## Что здесь есть

- **Статьи** о книгах, персонажах, Великих Домах, местах, событиях и понятиях мира.
- **Карта и шкала времени**: где и когда происходили главные события цикла.
- **3D-карта** материка с горами, реками, лесами, городами, железными дорогами и трактами.
- **Родословные** Великих Домов и **схема связей** персонажей.
- **Хронология**, **глоссарий**, **цитаты** и **иллюстрации**.
- **Испытания**: тесты на знание мира трёх уровней сложности с шутливым вердиктом в конце.

Всё написано по тексту цикла и «Путеводителю по землям Полари».

## Защита от спойлеров

Поле «Прочитано» в шапке сайта скрывает разделы статей о книгах, которые вы ещё не прочитали.
Общие разделы при этом размываются, а поздние события пропадают с карты, шкалы времени и схемы связей.

## Как устроен репозиторий

```
content/<тип>/<slug>.md   статьи (Markdown с шапкой; ссылки [[slug]] или [[slug|текст]])
data/                     указатель глав, родословные, Великие Дома, связи персонажей, точки на карте, вопросы испытаний (quiz.json)
data/changes.tsv          журнал новых и дополненных статей для страницы «Что нового» (ведёт build.py)
images.tsv                какие иллюстрации к каким статьям относятся
build.py                  собирает данные сайта в web/public/data/
web/scripts/pages.mjs     после сборки сайта пишет страницу на каждую статью (для поиска и превью ссылок), sitemap.xml и robots.txt
web/                      сайт на Angular
```

## Как запустить у себя

    python3 build.py              # пересобрать данные после правок в content/ или data/
    cd web && npm ci && npx ng serve

Сайт откроется на http://localhost:4200.
